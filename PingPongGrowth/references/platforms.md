# Platform Rules & Ranking Signals (2026)

Update this file every 6 months.

## X (Twitter)
- Bio ≤ 160 chars (Premium expanded)
- Post 280 / Premium 25k
- Signals: consistency, first-30-min replies, threads > singles, original > pure RT, links in reply, creator diversity cap
- Hook: question → counter → short thread resolution

## Instagram
- Bio ≤ 150
- Reels ideal 30–90s, first 1.7–3s critical
- Signals: watch time #1, DM shares & Saves > likes, keywords > hashtags (3–5 niche), niche consistency last 9–12 posts
- Hook: visual/verbal contradiction in first 3s → dialogue → share/save CTA

## YouTube
- Title: keyword first 40 chars, specific outcome
- Thumbnail: ≤4 words, mobile, emotion
- Shorts: first 1–2s, high completion
- Signals: CTR + watch time / session depth, deliver promise in 30s
- Hook: title/thumbnail as debate promise → open with conflict

## Facebook
- Signals: meaningful comments/shares, first 60 min, Groups weight high, 80/20 value
- Hook: direct question or poll that forces a side

## TikTok / 抖音
- First 3s critical, 5s Qualified View, completion rate core
- Ideal 15–30s (trend) / 30–60s (edu)
- Hook: instant visual/verbal tension → fast resolution

## 小红书
- Cover + first 3 lines decide CTR
- Search keywords core, lifestyle + practical
- Hook: pain-point question on cover/first lines → practical fused answer

## 视频号
- Dual: algorithm + friend endorsement (“朋友❤️”)
- 前3秒跳出 <45%, 30s留存 ≥60%, 有效评论 ≥8字
- Social seeding (朋友圈/群) first 1–2h critical
- Hook: 3s tension + explicit “转给正在纠结的朋友”

## 公众号
- Ranking weight: 完读率 > 分享率 > 在看率 > 关注转化
- Title: avoid 标题党; use 数字/提问/悬念/利益/对比; keyword front
- Hook: debate-style title → high-completion body that resolves the ping-pong

## Bilibili
- Series + 弹幕-friendly moments, searchable cover/title
- Hook: searchable title + early 弹幕 trigger point

## LinkedIn
- Professional insight + story, comment engagement
- Hook: industry contradiction → personal/professional resolution
