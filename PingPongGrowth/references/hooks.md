# Ping-pong Hooks & Cross-Platform Patterns

## Universal Ping-pong Structure
1. Trigger Question / Contradiction (what people are actually asking)
2. Opposing View or Emotional Tension (the other side of the dialogue)
3. Fused Insight as Resolution (your original synthesis)
4. Platform-Native CTA (invites the next “ping”)

Never copy surface sentences. Rebuild the dialogue flow.

## Cross-Platform Adaptation Example

Shared structure extracted from search:
- Question: “为什么努力却没结果？”
- Objection: “你方法错了 / 你不够努力”
- Missing middle: “努力方向比努力程度更重要”

### X version
Thread:
1. 为什么很多人努力却没结果？
2. 常见回答是“不够努力”。但真正的问题往往是方向。
3. 正确方向 × 持续行动 = 结果。你现在的方向清晰吗？

### Instagram Reels
0–3s: 画面文字 “努力却没结果？” + 冲突表情
3–15s: 快速对比两种努力
15–30s: 给出融合观点 + “转给正在迷茫的朋友”

### 视频号
前3s: 强冲突提问
中段: 对话式拆解
结尾: “转给正在纠结的朋友” + 引导 ≥8字评论

### 公众号
标题: 为什么你的努力总是没有结果？（提问+利益）
正文: 开头承诺价值 → 还原乒乓双方 → 给出融合框架 → 行动清单 → 自然引导在看/分享

### YouTube Shorts
Title: 努力却没结果？真正的原因只有一个
First 2s: 冲突画面
Body: 快速给出方向 > 努力的结论

Keep the core insight identical; only change packaging, length, and CTA.
